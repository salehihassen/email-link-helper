Installation steps

Chrome: unzip, open chrome://extensions, enable Developer mode, choose Load unpacked, then select the folder. To update, replace the files in that same folder and click Reload on its extension card; your settings are retained.

Firefox: unzip, open about:debugging → This Firefox → Load Temporary Add-on, and select manifest.json. Temporary installations disappear on restart; permanent installation requires signing.

Use the private source shown above. Allow host access only for that source. The badge checks about every 30 seconds while the browser is awake; opening the popup checks immediately. Links are removed from the helper when opened.
