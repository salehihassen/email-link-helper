01 / MAIL

Listening for your links

Bridge is checked every 5 seconds by default. Proton adds its own 20–40 second sync interval. Only allowlisted sender headers are considered; other message bodies are ignored.

02 / BROWSER

A small badge. One click.

Installation steps

Chrome: unzip, open chrome://extensions, enable Developer mode, choose Load unpacked, then select the folder.

Firefox: unzip, open about:debugging → This Firefox → Load Temporary Add-on, and select manifest.json. Temporary installations disappear on restart; permanent Firefox installation requires signing the extension.

In extension Settings, use the private source shown above. Allow host access only for that source. The badge checks about every 30 seconds while the browser is awake; opening the popup checks immediately. A link is removed from the helper as soon as you open it.

03 / SETTINGS

Your providers and rules

Add Proton Bridge or another provider with verified IMAPS, such as Zoho. Gmail is out of scope. Rules require an exact sender domain, passing DKIM from your receiving mail server, and exact HTTPS destination hosts and paths.

How to edit settings

Each provider needs an ID, label, type, username, mailboxes and trusted authserv_ids. For imap, also set host and port (993). To add or replace a password, enter it in that provider's password field; an empty value preserves the existing password. Saved passwords are encrypted and never returned.

Sender patterns permit * in the part before @. Configure authserv_ids from the first Authentication-Results block added by your receiving provider. DKIM checks use that provider's result, rather than independently verifying signatures.
